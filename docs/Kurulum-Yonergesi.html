WhatsYpzck Full Kurulum Yönergesi (Windows)

Versiyon: 2.1.0 | Tarih: 16.04.2026

1) Dağıtım Paketleri

  • Lisanslı: WhatsYpzck-Licensed-Full-Kurulum-Setup.exe
  • Lisanssız: WhatsYpzck-Unlicensed-Full-Kurulum-Setup.exe
  • Lisans Üretici: WhatsYpzck-License-Generator.exe

2) Kurulum Öncesi Kontrol

Full kurulum setup, eksikse otomatik olarak Node.js, MongoDB ve Google Chrome yüklemeyi dener.

Gereken: Yönetici yetkisi, internet erişimi, winget erişimi.

3) Kurulum Adımları

  1. Uygun setup dosyasını Yönetici olarak çalıştırın.
  2. Kurulum bitince otomatik setup scripti devreye girer.
  3. Script sırasıyla:
    • Node.js / MongoDB / Chrome kontrolü ve kurulumunu
    • .env dosyasının oluşturulmasını
    • PUPPETEER_EXECUTABLE_PATH değerinin yazılmasını
    • npm bağımlılıklarının yüklenmesini
    • Type check çalıştırılmasını
    • (Opsiyonel) Docker/Ollama adımlarını

4) İlk Açılış

  1. Başlatma için masaüstündeki kısa yolu veya start-whatsypzck.ps1 scriptini çalıştırın.
  2. Admin giriş sayfası: http://localhost:3000/admin/login
  3. Sağlık kontrolü: http://localhost:3000/health veya /status

5) AI ve Entegrasyon Ayarları

AyarNeredenNot

6) Lisans Üretimi

  1. WhatsYpzck-License-Generator.exe çalıştırın.
  2. Customer ID, müşteri adı, bitiş tarihi girin.
  3. Lisans dosyasını üretip hedef ortama taşıyın.

7) Güvenlik Sertleştirme Checklist

  • Admin paneli güçlü parola + rol tabanlı erişim
  • TLS reverse proxy (Nginx/Caddy) zorunlu
  • Gereksiz portların firewall ile kapatılması
  • Düzenli yedekleme ve log izleme
  • Aylık patch ve npm audit
  • Not: Mutlak güvenlik garantisi yoktur; katmanlı savunma uygulanmalıdır.
