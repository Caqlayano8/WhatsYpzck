Yeni Bilgisayar — Offline EXE ile Kurulum

ℹ️
Bu yöntem kimler içindir? Uygulamayı VS Code, Node.js veya teknik bilgi olmadan başka bir Windows bilgisayara kurmak isteyenler. Sadece bir EXE dosyasını çalıştırmak yeterlidir.

📦 Aşama A — EXE Dosyasını Hazırlama (Geliştirici bilgisayarında)

Bu aşama yalnızca bir kez geliştirici tarafında yapılır. Oluşturulan EXE daha sonra USB veya internet üzerinden hedefe kopyalanır.

  • 1
    PowerShell'i Yönetici Olarak Açın

    Başlat → "PowerShell" yazın → Sağ tıkla → Yönetici olarak çalıştır

  • 2
    Proje klasörüne gidin
    cd 'C:\Users\34116\Desktop\WhatsYpzck'
  • 3
    EXE hazırlama scriptini çalıştırın

    Bu komut: Node.js + MongoDB + Chromium indirir, uygulamayı derler, EXE'yi oluşturur.

    .\scripts\windows\build-offline-package.ps1

    ⏱️ İlk seferinde 5–15 dakika sürebilir (internet hızına bağlı).

  • 4
    Inno Setup kurun (eğer yoksa)

    Script Inno Setup bulamazsa uyarı verir. Şuradan indirin ve kurun:

    # İndirme adresi:
    https://jrsoftware.org/isdl.php

    Kurumdan sonra scripti tekrar çalıştırın.

  • 5
    EXE hazır! Şu konumda bulunur:
    C:\Users\34116\Desktop\WhatsYpzck\installer\output\
    WhatsYpzck-Offline-Kurulum-Setup-v2.0.0.exe

    Bu EXE dosyasını USB, e-posta veya paylaşımlı klasör ile hedefe kopyalayın.

✅
İpucu: Tekrarlanan buildlerde hız kazanın Portable dosyalar zaten installer\redist\ klasöründeyse script tekrar indirmez. Sadece build ve EXE adımlarını çalıştırır.

💿 Aşama B — Hedef Bilgisayara Kurulum (Son kullanıcı tarafında)

ℹ️
Gereksinimler: Windows 10/11 64-bit  ·  Yönetici hesabı  ·  Başka hiçbir şey gerekmez. Node.js, MongoDB, VS Code kurulu olmak zorunda değil.
  • 1
    EXE dosyasını kopyalayın

    USB, e-posta veya ağ paylaşımı yoluyla WhatsYpzck-Offline-Kurulum-Setup-v2.0.0.exe dosyasını hedef bilgisayara aktarın.

  • 2
    EXE'ye sağ tıklayın → Yönetici Olarak Çalıştır

    Windows Defender uyarısı çıkarsa: "Daha fazla bilgi" → "Yine de çalıştır" tıklayın.

  • 3
    Kurulum sihirbazını takip edin

    Varsayılan ayarlar ile ilerleyin. Kurulum dizini: C:\Program Files\WhatsYpzck\

  • 4
    Kurulum tamamlanınca "Şimdi Başlat" kutucuğunu işaretleyin

    Uygulama otomatik başlar, tarayıcıda Admin Paneli açılır.

📱 Aşama C — İlk WhatsApp Bağlantısı (QR Tarama)

  • 1

    Tarayıcıda otomatik açılır. Elle açmak için: http://localhost:XXXX/admin

  • 2
    QR sayfasına gidin

    http://localhost:XXXX/qr adresine gidin — büyük bir QR kodu görünür.

  • 3
    WhatsApp'tan tarayın

    Telefon → WhatsApp → ⋮ (Üç nokta) → Bağlı Cihazlar → Cihaz Bağla → QR'ı tarayın.

  • 4
    Bot aktif!

    Admin panelde "Client is ready!" mesajı görünce bot hazırdır.

VS Code Olmadan Başlatma (Günlük Kullanım)

Kurulum tamamlandıktan sonra uygulamayı her gün başlatmak için yalnızca bu tek adım yeterlidir:

🖱️

launch.bat dosyasına çift tıklayın

C:\Program Files\WhatsYpzck\launch.bat

veya masaüstündeki WhatsYpzck kısayoluna tıklayın.

launch.bat Ne Yapar?

🔐 1. Yönetici izni alır

MongoDB gibi sistem servislerini başlatabilmek için otomatik olarak yönetici haklarıyla çalışır.
🗄️ 2. MongoDB'yi başlatır

Portable MongoDB (gömülü) otomatik başlar. Sistem MongoDB servisi varsa onu kullanır.
🔌 3. Boş port bulur

.env'deki PORT değerini dener. Meşgulse 3501, 3502... diye boş port bulana kadar devam eder.
🌐 4. Browser açar

Uygulama hazır olunca Admin Paneli tarayıcıda otomatik açılır.
💡
Konsol penceresi açılır — bu normal! Siyah bir PowerShell penceresi açılır ve loglar görünür. Bu pencereyi kapatmak uygulamayı durdurur. Arka planda çalıştırmak istiyorsanız pencereyi küçültün.

Port Numarasını Nereden Öğrenirim?

Konsol penceresinde şuna benzer bir satır görünür:

[WhatsYpzck] ✔ Uygulama PID: 12345
[WhatsYpzck] ⚠ Port 3500 meşgul, 3501 kullanılıyor.
[WhatsYpzck] ✔ WhatsYpzck hazır → http://localhost:3501/admin

Admin panele erişmek için tarayıcıda o adresi kullanın.

Uygulamayı Durdurmak

Yöntem 1 — Konsol penceresi

Açık siyah PowerShell penceresini kapatın.
Yöntem 2 — Ctrl+C

Konsol penceresinde Ctrl + C tuş kombinasyonu.

Port Otomatik Bulma

WhatsYpzck artık port meşgul olduğunda otomatik olarak bir sonraki boş portu bulup kullanır. Bu özellik hem yerel hem de sunucu ortamında çalışır.

Nasıl Çalışır?

  1. Uygulama açılırken .env dosyasındaki PORT değerini okur (varsayılan: 3500).
  2. O port meşgulse bir sonrakini (3501, 3502…) dener.
  3. Bulduğu portta çalışmaya başlar ve log'a yazar.
  4. Launcher (start-installed.ps1) da aynı mantıkla portu bulur ve doğru adresi açar.
src/index.ts — findFreePort() fonksiyonu /** Verilen port meşgulse bir sonrakini dener — offline, async. */
function findFreePort(startPort: number): Promise<number> {
    return new Promise((resolve) => {
        const server = net.createServer();
        server.listen(startPort, '0.0.0.0', () => {
            const addr = server.address() as net.AddressInfo;
            server.close(() => resolve(addr.port));
        });
        server.on('error', () => findFreePort(startPort + 1).then(resolve));
    });
}
💡
Hangi port kullanıldığını öğrenmek için: Konsol penceresine bakın. Server running on port XXXX satırını arayın. Ya da http://localhost:3500/health deneyip port meşgulsa 3501, 3502... deneyin.

Port Yönetimi İpuçları

Durum Sonuç
.env'de PORT=3500, port boş ✅ 3500'de başlar
.env'de PORT=3500, meşgul ⚡ 3501'de otomatik başlar, log'a yazar
PORT tanımlı değil ⚡ 3500'den başlayarak boş port arar
Hosting ortamı (PORT env var) ✅ Platformun verdiği PORT kullanılır

Sık Sorulan Sorular & Sorun Giderme

❓ "MongoDB bağlanamıyorum" hatası

Neden olur: MongoDB servisi çalışmıyor veya port 27017 meşgul.

Çözüm (Windows):

# MongoDB servisini başlat
Start-Service MongoDB
# veya elle:
mongod --dbpath "C:\data\db" --port 27017

Çözüm (Portable): launch.bat otomatik başlatır. Hata olursa data\mongodb\ klasörünün boş olmadığını kontrol edin.

❓ "PUPPETEER_EXECUTABLE_PATH eksik" hatası

Neden olur: Chromium/Chrome bulunamıyor.

Çözüm 1: Google Chrome kurun — script otomatik bulur.

Çözüm 2: .env dosyasına elle ekleyin:

PUPPETEER_EXECUTABLE_PATH=C:\Program Files\Google\Chrome\Application\chrome.exe

❓ QR kodu görünmüyor

Adım 1: http://localhost:PORT/qr adresini doğrudan ziyaret edin.

Adım 2: Admin panelde "Bot Başlat" butonu varsa tıklayın.

Adım 3: Konsol penceresinde hata varsa .wwebjs_auth\ klasörünü silip yeniden başlatın:

# WhatsApp oturumu sıfırla
Remove-Item '.wwebjs_auth' -Recurse -Force
# Sonra uygulamayı yeniden başlatın

❓ Browser açılmıyor / Admin paneline erişemiyorum

Konsoldaki porta dikkat edin. Tarayıcıda şunları deneyin:

http://localhost:3500/admin
http://localhost:3501/admin
http://127.0.0.1:3500/admin

❓ "Windows Defender EXE'yi engelledi"

EXE dosyasına sağ tıkla → Özellikler → En altta "Engeli kaldır" kutucuğunu işaretle → Tamam → Tekrar çalıştır.

❓ Hosting'de bot çalışıyor ama WhasApp bağlanmıyor

Cloud ortamında WhatsApp oturumu ilk bağlantı sonrası .wwebjs_auth\ klasöründe saklanır. Servis yeniden başladığında bu klasör silinirse QR tekrar taranmalıdır. Kalıcı storage için:

  • Render: Persistent Volume ekleyin → /opt/render/project/src/.wwebjs_auth
  • VPS: Klasörü volume mount edin
  • Docker: docker-compose.yml'deki volumes bölümünü kullanın

winget install JRSoftware.InnoSetup

Kurulum Öncesi Kontrol Listesi

🖥️ Yerel / Offline Kurulum İçin

  • Windows 10/11 64-bit bilgisayar
  • Yönetici (admin) hesabı
  • İnternet bağlantısı (sadece EXE hazırlama aşamasında)
  • Inno Setup 6 kurulu (geliştirici bilgisayarında)
  • build-offline-package.ps1 başarıyla tamamlandı
  • installer\output\*.exe dosyası oluştu
  • EXE hedef bilgisayara kopyalandı
  • EXE yönetici olarak çalıştırıldı
  • WhatsApp QR kodu tarandı

🌐 Hosting Kurulumu İçin

  • MongoDB Atlas cluster oluşturuldu
  • Atlas connection string alındı
  • JWT_SECRET (min 32 karakter) oluşturuldu
  • ENCRYPTION_MASTER_KEY (64 hex) oluşturuldu
  • DEFAULT_ADMIN_PASS belirlendi (güçlü)
  • SMTP ayarları yapılandırıldı (e-posta için)
  • ARIZA_TEAM_WHATSAPP numarası girildi
  • Deploy başarıyla tamamlandı
  • WhatsApp QR kodu cloud ortamında tarandı
  • Admin şifresi değiştirildi (ilk girişten sonra)

🔑 Güvenlik Değerleri Üretme

PowerShell # JWT_SECRET oluştur (min 32 karakter)
[System.Web.Security.Membership]::GeneratePassword(48, 8)
# veya:
[System.Convert]::ToBase64String([System.Security.Cryptography.RandomNumberGenerator]::GetBytes(32))

# ENCRYPTION_MASTER_KEY oluştur (64 hex karakter)
([System.Security.Cryptography.RandomNumberGenerator]::GetBytes(32) |
  ForEach-Object { $_.ToString('x2') }) -join ''
🔒
Güvenlik Uyarısı: JWT_SECRET, ENCRYPTION_MASTER_KEY ve DEFAULT_ADMIN_PASS değerlerini kesinlikle varsayılan bırakmayın. Her kuruluşa özel güçlü değerler oluşturun. Bu değerleri Git'e commit etmeyin ve başkalarıyla paylaşmayın.

📊 Multi-Step Memnuniyet Anketi

Arıza kaydı ÇÖZÜMLENDI statüsüne alındığında müşteriye otomatik olarak 3 adımlı WhatsApp anketi gönderilir.

AdımBot SorusuBeklenen Yanıt
1Probleminiz çözüldü mü?1 = Evet  /  2 = Hayır
2Teknisyen iletişiminden memnun kaldınız mı?1 = Evet  /  2 = Hayır
3Belirtmek istediğiniz başka bir konu var mı?Serbest metin  /  "Hayır" yazarak geç

Admin Panelden Anket Yönetimi

  1. Admin Panel → Anketler → Anket Ayarları sekmesini açın
  2. "Anketi Etkinleştir" toggle'ını açın
  3. İlk mesaj ve teşekkür mesajını özelleştirin ({{customerName}}, {{incidentId}} değişkenleri kullanılabilir)
  4. Ayarları Kaydet butonuna tıklayın

Sonuçları Admin → Anketler sayfasında müşteri telefonu veya arıza numarasına göre filtreleyerek görüntüleyin.

👤 Manuel Kişi Ekleme

Daha önce yalnızca WhatsApp üzerinden mesaj atan kişiler sisteme eklenebiliyordu. Artık admin panelden manuel olarak da kişi eklenebilir.

  1. Admin Panel → Kişiler sekmesini açın
  2. Sağ üstteki "Kişi Ekle" butonuna tıklayın
  3. Telefon numarası (ülke kodu dahil, örn: 905551234567), ad, soyad ve adres girin
  4. Ekle butonuna tıklayın

Aynı telefon numarası zaten kayıtlıysa sistem hata mesajı gösterir.
